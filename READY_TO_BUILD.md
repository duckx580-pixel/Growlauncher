## 📦 Quick Build Instructions

### **From Your Computer:**

```bash
# 1. Clone from GitHub
git clone <your-github-repo-url>
cd frontend

# 2. Run the build script (ONE COMMAND!)
bash build.sh
```

That's it! The script will:
- ✅ Install EAS CLI
- ✅ Login to Expo
- ✅ Build Android APK
- ✅ Build iOS app
- ✅ Give you download links

---

## 📱 **Or Build Manually:**

### Android APK:
```bash
cd frontend
npm install -g eas-cli
eas login
eas build --platform android --profile preview
```

### iOS Installation Link:
```bash
eas build --platform ios --profile preview
```
